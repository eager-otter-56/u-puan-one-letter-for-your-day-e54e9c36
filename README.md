Entry for the make.fun bounty "One Letter for Your Day". Running `main.py` writes exactly one character — the letter **U**, for *underwater*: a day held below the surface of messages, tabs and small urgencies, surfacing only for coffee — to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
